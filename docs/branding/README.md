# Branding assets

Social-media and internal branding imagery for ewcalc, in the OldCrow
house style (hairline measurement, Italiana + mono, one gold accent) but
outside the corvid-cartography field guide — an application plate, series
"plate i". The SVGs are the canonical sources; all text is outlined as
paths, so they render identically without any installed fonts. PNGs are
exports of the SVGs. Masters carry no version number — stamp one ad hoc
for a release if wanted.

The dark files are the masters. The `-light` files are an official
secondary variant for print, docs headers, or in-app use.

| File | Size | Use |
|---|---|---|
| `ewcalc-github-social.{svg,png}` (+`@2x`) | 1280×640 (2:1) | GitHub repository social preview (master) |
| `ewcalc-linkedin.{svg,png}` (+`@2x`) | 1200×627 | LinkedIn link/post card (master) |
| `ewcalc-github-social-light.{svg,png}` (+`@2x`) | 1280×640 | Light variant |
| `ewcalc-linkedin-light.{svg,png}` (+`@2x`) | 1200×627 | Light variant |

Design concept and rules are in
[philosophy-the-emitter-located.md](philosophy-the-emitter-located.md).

Palette — dark master: ink `#161b23`, cream `#e7e0cf`, gold `#c8a24e`.
Light variant: ground `#dde4ef` (ink hue tinted toward white), linework
`#5f4a1d` (gold family deepened), same gold accent.
